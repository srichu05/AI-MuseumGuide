# AI Museum Guide

A multimodal museum website with **Visual Artifact Recognition** and **Knowledge-Based Conversational QA**.

This is an academic NLP/IR project — traditional local NLP and IR perform intent classification, entity extraction, dialogue management, SQLite querying, BM25/TF-IDF retrieval, and factoid extraction. **GroqCloud is used only** for visual artifact identification and final natural-language response generation from verified facts.

## Architecture

```
Visitor → Image/Text → Local NLP Pipeline → Dialogue Manager
                              ↓
                    SQLite + BM25/TF-IDF + Factoid QA
                              ↓
                    Verified Facts → GroqCloud → Answer + Sources
```

## Prerequisites

- Python 3.10+

## Setup

### 1. Backend

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
python -m spacy download en_core_web_sm

# Configure environment
copy .env.example .env   # Windows
# cp .env.example .env   # macOS/Linux
# Edit .env and set GROQ_API_KEY

# Seed database (60 artifacts, 20 artists, documents, BM25 index built on startup)
python -m database.seed

# Run Flask API
python app.py
```

Backend runs at **http://localhost:5000**

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at **http://localhost:3000**

Optional: create `frontend/.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Health check |
| GET | `/api/artifacts` | List artifacts (filters: search, period_id, artist_id, gallery_id, type) |
| GET | `/api/artifacts/<id>` | Artifact detail + exhibitions + related works |
| GET | `/api/artists/<id>` | Artist profile + works |
| GET | `/api/galleries` | Galleries with artifact counts |
| GET | `/api/exhibitions` | List exhibitions |
| POST | `/api/identify` | Upload image → GroqCloud vision → SQLite validation |
| POST | `/api/chat` | Full NLP/IR/chat pipeline |
| POST | `/api/query` | Alias for chat |
| POST | `/api/search` | BM25/TF-IDF document search |

## User Flow

1. Browse collection at `/collection`
2. Open artifact detail → "Ask Museum AI"
3. Upload artifact image at `/guide` → visual identification
4. Ask questions: "Who created this?", "Where is it?", "Tell me about its history"
5. Local NLP classifies intent, resolves "it/this" via dialogue state
6. SQLite or BM25+factoid QA retrieves verified facts
7. GroqCloud generates natural response; sources displayed in UI
